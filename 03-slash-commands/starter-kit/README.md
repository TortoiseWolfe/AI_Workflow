# Starter kit: 30 slash commands

These 30 commands work in any Docker-first project with Claude Code installed. Copy the whole folder into your project's `.claude/commands/` directory and they work immediately.

The files live in a hidden folder, so this site cannot list them. Browse and copy them on GitHub: [the 30 command files](https://github.com/TortoiseWolfe/AI_Workflow/tree/main/03-slash-commands/starter-kit/.claude/commands).

The kit by family:

- **Priming (3):** prep, prime, prime_repositories
- **SpecKit (10):** speckit.specify, speckit.clarify, speckit.plan, speckit.tasks, speckit.implement, speckit.analyze, speckit.checklist, speckit.constitution, speckit.taskstoissues, speckit.workflow
- **Git (2):** commit, ship
- **Quality (4):** code-review, security-audit, secrets-scan, audit
- **Testing (5):** test, test-a11y, test-components, test-fail, test-hooks
- **Session (4):** session-stats, session-summary, status, clean-start
- **Reading (2):** read-spec, read-issues
