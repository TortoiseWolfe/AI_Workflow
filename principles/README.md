# Principles

Each principle is one rule and the incident that earned it. Read the war story first; the rule makes sense after it.

- [Context hygiene](context-hygiene.md) — keep the model's working memory clean so it stays accurate.
- [Docker-first](docker-first.md) — run package managers, builds and tests inside containers, never on the host.
- [Five-file components](five-file-components.md) — every component ships as the same five files.
- [Secrets never committed](secrets-never-committed.md) — keep keys and tokens out of the repository.
- [Spec before code](spec-before-code.md) — write down what you are building before the AI builds it.
